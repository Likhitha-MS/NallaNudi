# Nalla-Nudi 📘

## Formal English–Kannada Dictionary App

Nalla-Nudi is an Android-based educational dictionary application developed to help Kannada-medium students understand English technical terms used in subjects like Science, Mathematics, and Commerce. The application provides Kannada meanings, simple explanations, pronunciation support, and offline accessibility for easier learning.

---

## 📱 Features

- Search English technical terms
- View Kannada meanings and explanations
- Subject-wise filtering (Science, Maths, Commerce)
- Pronunciation support using Text-to-Speech
- Save important words for revision
- Remove or clear saved words
- Offline JSON dataset support
- Modern dark theme UI
- About Developer section
- Fully offline application

---

## 🎯 Problem Statement

Kannada-medium students often face difficulty understanding English technical vocabulary used in academics. Existing dictionary apps do not provide subject-specific technical meanings with simple Kannada explanations. Nalla-Nudi was developed to reduce this language barrier through a simple and offline mobile application.

## 🏗️ Project Modules

### 1. Search Feature
Users can search English technical words and view Kannada meanings with explanations.

### 2. Subject Filters
Words can be filtered based on:
- Science
- Maths
- Commerce

### 3. Pronunciation Support
Android Text-to-Speech API is used for English word pronunciation.

### 4. Saved Words
Users can save important words locally for future revision.

### 5. Offline Support
All words are stored using JSON datasets, enabling complete offline access.
